# Domain docs

Один контекст для backend і frontend; поділ каталогів не створює окремих доменів.

Перед роботою з термінами або моделлю даних прочитайте кореневий `GLOSSARY.md`.
Перед зміною відповідного рішення прочитайте ADR у `docs/adr/`.

- ADR 0001 — хостинг, зовнішній розклад і робота після засинання.
- ADR 0002 — природний ключ поста й часові спостереження метрик.
- ADR 0003 — Gemini і кешований дайджест.

Словник містить визначення доменних понять. API, таблиці, числові межі й критерії
готовності належать до `docs/spec.md`, а порядок роботи — до плану та Issues.
Конфлікт із прийнятим ADR потрібно явно розібрати перед зміною рішення.
