# 04: Аналітика та деталі поста

Part of [#1](https://github.com/virus231/channel-radar/issues/1).

**What to build:** Користувач бачить огляд каналів, відкриває канал із графіками й
періодом, переглядає список і деталі поста та переходить до Telegram-оригіналу.

**Blocked by:** [#4](https://github.com/virus231/channel-radar/issues/4).

**Status:** ready-for-agent

## Acceptance criteria

- [ ] Огляд має підписників, кількість збережених постів, час останнього успіху й здоров’я кожного джерела.
- [ ] Сторінка каналу має графік підписників за observed_at, posts/day за published_at, середні перегляди та посторінковий список постів.
- [ ] Фільтр дат працює за узгодженими UTC межами; UI пояснює реальне покриття збором і default 7 днів.
- [ ] Деталі поста показують текст, останні counters, їх історію та посилання на оригінал.
- [ ] Null counters, порожній період і недостатня історія показуються коректно, без вигаданих нулів або графічних точок.
- [ ] Offline arithmetic tests підтверджують середнє 200 для 100/300/null і 50 для 0/100, приріст підписників і межі UTC.
- [ ] UI тести перевіряють фільтр і navigation; вузький екран, довгий текст і пряме перезавантаження detail route перевірені браузером.

## Verification

Pytest відомих прикладів аналітики й дат; frontend typecheck/build/UI tests;
deployed desktop/mobile-width smoke для всіх трьох React routes.
