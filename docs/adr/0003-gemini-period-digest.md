# Gemini і кешований дайджест за період

AI-функція MVP — дайджест збережених постів за вибраний період: ключові теми,
коротке резюме й посилання на пости. Обрано Gemini `gemini-3.5-flash-lite` з
безкоштовним рівнем; для цієї задачі не потрібні мультимодальність або окремий
провайдер для кожного виду аналізу.

Результат зберігається разом із періодом, моделлю та fingerprint вхідних постів.
Повторний запит незміненого зрізу використовує кеш. Публічні тексти є даними,
а не інструкціями для LLM; посилання формуються лише на передані пости. Timeout,
429 або невалідна відповідь впливають лише на дайджест: дашборд і збір працюють,
користувач бачить причину та може повторити спробу. Інші LLM-провайдери не додаються.

Доступність моделі й free tier перевірені 2026-10-08:
[моделі Gemini](https://ai.google.dev/gemini-api/docs/models),
[тарифи](https://ai.google.dev/gemini-api/docs/pricing). Перед реальним деплоєм
потрібно перевірити доступну квоту для конкретного ключа.
