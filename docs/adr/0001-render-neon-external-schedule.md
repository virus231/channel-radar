# Render, Neon і зовнішній розклад

Для триденного MVP обрано один Render Free Web Service, який віддає FastAPI API та
зібраний React, і Neon Free Postgres для постійних даних. Це простіше за Cloud Run
із billing-акаунтом і не прив’язує дані до тимчасової файлової системи Render або
30-денного терміну його безкоштовного Postgres.

cron-job.org перевіряє `/healthz` без звернення до БД кожні 10 хвилин і запускає
захищений збір кожні 30 хвилин. Збір починається після швидкої HTTP-відповіді, тому
не залежить від 30-секундного ліміту зовнішнього тригера. Перезапуск сервісу може
перервати збір; наступний виклик відновлює його без дублікатів. Холодний старт і
квоти залишаються обмеженнями безкоштовної схеми, а успіх HTTP-тригера не означає
успішний збір усіх каналів.

Умови перевірені 2026-10-08: [Render Free](https://render.com/docs/free),
[платність Render cron jobs](https://render.com/docs/cronjobs),
[Neon Free](https://neon.com/blog/neon-free-plan-1-gb-per-project),
[cron-job.org FAQ](https://cron-job.org/en/faq/).
